# 100円note制作・販売AIチーム

「氣功整体カイロプラクティック大江」の100円noteを、企画から販売・振り返りまで5つの役割で分担して進めるための仕組みです。
各役割の詳しい指示は `.claude/agents/` にあります。

## チーム構成

| 役割 | エージェント名 | 主な仕事 | 成果物 |
|------|----------------|----------|--------|
| 編集長 | `note-editor-in-chief` | テーマ企画・構成・指示・最終の公開判断 | 企画書、公開判断 |
| ライター | `note-writer` | 本文の執筆(セルフケア・患者事例) | 原稿 |
| 校閲 | `note-proofreader` | 誤字脱字・医療広告/薬機法・個人情報・安全性の確認 | 校閲レポート、校閲済み原稿 |
| デザイナー | `note-designer` | 見出し画像・図解・Instagram画像の指示書 | デザイン指示書 |
| 販売担当 | `note-sales` | タイトル・タグ・告知文・公開日時・振り返り | 販売素材、振り返り記録 |

## 作業の流れ

```
①編集長:企画書        → note/01_企画/
      ↓
②ライター:執筆        → note/02_原稿/
      ↓
③校閲:確認 ──修正必要──→ ②へ差し戻し
      ↓ OK              → note/03_校閲済/
      ├────────────┐
④デザイナー        ⑤販売担当   (同時に進める) → note/04_販売素材/
      └────────────┘
      ↓
⑥編集長:公開前チェック ──NG──→ 該当の担当へ差し戻し
      ↓ GO
⑦院長がnoteに投稿・公開
      ↓
⑧販売担当:1週間後に振り返り → 次の企画へ反映
```

## 使い方

Claude Codeで、次のように役割を指定して頼みます。

- 「note-editor-in-chief で『デスクワークの首こり』の企画書を作って」
- 「note-writer で 01_企画/20261101_首こり.md の原稿を書いて」
- 「note-proofreader で 02_原稿/20261101_首こり.md を校閲して」
- 「note-designer と note-sales で 03_校閲済/20261101_首こり.md の素材を作って」
- 「note-editor-in-chief で公開前チェックをして」

## 工程ごとの合格ライン(要約)

| 工程 | 次に進める条件 |
|------|----------------|
| 企画 | 企画チェック12点以上/15点、患者事例の同意あり |
| 執筆 | 自己チェック全項目✔、有料部分2,000〜4,000字 |
| 校閲 | 法令・表現チェックに該当なし、判定「OK」 |
| デザイン | 画像の文言が校閲済み原稿と一致、素材の商用利用OK |
| 販売 | タイトル・タグ5〜8個・告知文・公開日時・導線がそろう |
| 公開判断 | 編集長の公開前チェック全項目✔ |

## 全員が守る共通ルール

1. **「治る」と約束しない**:効果を保証する表現・根拠のない比較はしない
2. **患者のプライバシーを守る**:同意のない事例は使わない。特定できる情報は書かない・写さない
3. **安全第一**:痛み・しびれが強い場合は受診をすすめる。セルフケアには回数・強さの上限を書く
4. **100円以上の価値を**:検索すれば分かる内容ではなく、院長の経験が入った内容にする
