# 100円note制作・販売AIチーム

100円noteを、テーマ決定から販売・振り返りまで5つの役割で分担して進めるための仕組みです。
(このnoteは整体院の業務とは関係のない、個人のnote活動として運用します)
各役割の詳しい指示は `.claude/agents/` にあります。

## チーム構成

| 役割 | エージェント名 | 主な仕事 | 成果物 |
|------|----------------|----------|--------|
| 編集長 | `note-editor-in-chief` | 読者の悩みを分析してテーマを決定、最終の公開判断 | 悩み分析シート、企画書、公開判断 |
| ライター | `note-writer` | noteの構成と本文の作成 | 構成案つき原稿 |
| 校閲担当 | `note-proofreader` | 誤字・言い回し・内容のチェック | 校閲レポート、校閲済み原稿 |
| デザイナー | `note-designer` | 表紙画像の案、タイトル・見出し案の提案 | デザイン提案書 |
| 販売担当 | `note-sales` | 公開設定、Threadsの告知投稿、導線の設計、振り返り | 販売素材、振り返り記録 |

## 作業の流れ

```
①編集長:悩みを分析 → テーマ決定     → note/01_企画/
      ↓
②ライター:構成 → 本文             → note/02_原稿/
      ↓
③校閲:誤字・言い回し・内容 ──修正必要──→ ②へ差し戻し
      ↓ OK                          → note/03_校閲済/
④デザイナー:表紙・タイトル・見出し案  → note/04_販売素材/
      ↓
⑤販売担当:公開設定・導線・Threads告知 → note/04_販売素材/
      ↓
⑥編集長:公開前チェック ──NG──→ 該当の担当へ差し戻し
      ↓ GO
⑦noteに投稿・公開/Threadsで告知(3日前〜1週間後)
      ↓
⑧販売担当:1週間後に振り返り → 次のテーマ決定へ反映
```

## 使い方

Claude Codeで、次のように役割を指定して頼みます。

- 「note-editor-in-chief で『一人暮らしの節約』について読者の悩みを分析して、テーマを決めて」
- 「note-writer で 01_企画/20261101_〇〇.md の構成と本文を作って」
- 「note-proofreader で 02_原稿/20261101_〇〇.md を校閲して」
- 「note-designer で 03_校閲済/20261101_〇〇.md の表紙と見出し案を出して」
- 「note-sales で Threadsの告知投稿と導線を作って」
- 「note-editor-in-chief で公開前チェックをして」

## 工程ごとの合格ライン(要約)

| 工程 | 次に進める条件 |
|------|----------------|
| テーマ決定 | 悩みを10個以上集めて分析、テーマ決定チェック12点以上/15点 |
| 構成・本文 | 自己チェック全項目✔、有料部分2,000〜4,000字 |
| 校閲 | 内容の誤り・言いすぎなし、判定「OK」 |
| デザイン | タイトル5案・見出し案・表紙2案がそろい、本文より言いすぎていない |
| 販売 | Threads告知5投稿・導線マップ・公開日時・プロフィールのリンクがそろう |
| 公開判断 | 編集長の公開前チェック全項目✔ |

## 全員が守る共通ルール

1. **言いすぎない**:タイトル・表紙・告知を含め、本文で約束できること以上は書かない
2. **100円以上の価値を**:検索すればすぐ分かる内容ではなく、経験や工夫が入った内容にする
3. **読者の時間を大切に**:無料部分だけでも1つは持ち帰れるものを入れる
4. **権利を守る**:他人の文章・画像は無断で使わない。素材は商用利用OKのものだけ
