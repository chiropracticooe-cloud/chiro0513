### 土台づくり(11/2〜11/6、5本から毎日1本)

※ Threads担当が見直した最終版は `note/05_Threads/20261102_週の投稿.md`。投稿にはそちらを使う。

**土台①**
```
40代になってからの恋愛、
「今さら恋愛なんて」と思っていませんか。

実は、20年前より今のほうが
「恋愛したい」と考える40代は多い、という調査もあります。

恋愛したい気持ちに、年齢は関係ありません。
```

**土台②**
```
初対面の人と話したあと
「つまらないと思われたかも」と落ち込むこと、ありませんか。

心理学では、人は会話のあと
「相手が自分をどれくらい好意的に見ていたか」を
低く見積もりやすいことが分かっています。

あなたの印象は、思っているより良いかもしれません。
```

**土台③**
```
デートで会話が続かないときは、
自分が話すことより「相手に聞くこと」を考えると楽になります。

相手の答えに、もう一歩だけ質問を重ねる。
「どこに行ったんですか?」
「どのあたりが楽しかったですか?」

それだけで、会話は自然につながります。
```

**土台④**
```
「また今度ごはん行きましょう」

この「また今度」、社交辞令に聞こえやすい言葉です。

本当にまた会いたいなら、
「来週か再来週、〇〇に行きませんか?」と
日にちや行き先を具体的に。

それだけで、気持ちはちゃんと伝わります。
```

**土台⑤**
```
大人のデートで、少しの沈黙は自然なことです。

焦って話題を探すより、
「このお店、落ち着きますね」
と目の前のものを話題にすると、無理なく会話が戻ります。

沈黙は、失敗ではありません。
```
