# 氣功整体カイロプラクティック大江 予約・問診管理アプリ

患者さん向けの「予約フォーム」「問診票フォーム」と、院向けの「管理画面」をひとつにまとめたWebアプリです。

- `/` … トップページ（予約・問診票への案内）
- `/reserve` … 予約フォーム（メニュー・日時を選んで予約）
- `/questionnaire` … 問診票フォーム
- `/admin` … 管理画面（予約一覧・ステータス変更、要ログイン）
- `/admin/questionnaires` … 問診票一覧・詳細（要ログイン）

データはSQLite（`data/app.db`）にそのまま保存されます。外部サービスの契約は不要です。

## セットアップ

```bash
cd reservation-app
npm install
cp .env.example .env
```

`.env` を開いて以下を実際の値に変更してください。

```
ADMIN_PASSWORD=管理画面用のパスワード
SESSION_SECRET=ログインセッションの署名に使うランダムな文字列（32文字程度推奨）
```

## 開発時の起動

```bash
npm run dev
```

`http://localhost:3000` でアクセスできます。

## 本番起動

```bash
npm run build
npm run start
```

## 院の情報・営業時間・メニューの変更方法

`lib/config.ts` に以下がまとまっています。実際の内容に合わせて書き換えてください。

- `CLINIC_NAME` / `CLINIC_URL`: 院名・公式サイトURL
- `MENU_ITEMS`: 施術メニューと所要時間
- `BUSINESS_HOURS`: 曜日ごとの営業時間（`null` はその曜日が定休日）
- `SLOT_INTERVAL_MIN`: 予約枠を区切る単位（分）
- `MAX_BOOKING_DAYS_AHEAD`: 何日先まで予約を受け付けるか
- `PAIN_AREAS`: 問診票の「気になる部位」の選択肢

現時点の営業時間・定休日はサンプル値です。**公開前に必ず実際の内容に修正してください。**

## デプロイについて

このアプリはSQLiteのファイルにデータを保存するため、デプロイ先はファイルシステムが永続化される環境を選んでください。

- **VPS・自宅サーバーなど自前のサーバーに置く場合**: `npm run build && npm run start` をそのまま使えます。`pm2` などのプロセス管理ツールと組み合わせるのがおすすめです。
- **Railway / Render など**: 永続ディスク（Persistent Volume）を有効にし、`DB_PATH` 環境変数でそのディスク上のパスを指定してください（例: `DB_PATH=/data/app.db`）。
- **Vercelは非推奨**: Vercelはファイルシステムが実行ごとにリセットされるため、SQLiteのデータが消えてしまいます。Vercelを使いたい場合は、別途データベースサービス（例: Turso, Supabaseなど）への切り替えが必要です。

## 管理画面の使い方

1. `/admin/login` で `.env` に設定したパスワードでログイン
2. `/admin` で予約一覧を確認し、ステータス（未確定・確定・キャンセル）を変更したり、日付で絞り込みできます
3. `/admin/questionnaires` で問診票の一覧・詳細を確認できます
